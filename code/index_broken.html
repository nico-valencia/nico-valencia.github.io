Shear-Wave Splitting Toolkit

A Python-based workflow for measuring shear-wave splitting from SKS and direct S phases. Includes automated waveform retrieval, quality control, splitting intensity calculations, and multi-layer anisotropy fitting.

Python · ObsPy · NumPy · Matplotlib

In development — code will be released with publication

Receiver Function Processing

Scripts for computing and analyzing Ps receiver functions, with applications to ice sheet structure in Antarctica. Includes synthetic receiver function generation and forward modeling.

Python · ObsPy · SciPy

Developed during Brown University REU

Tools for creating publication-quality maps and figures for seismology research. Includes templates for splitting measurements, receiver function stacks, and station/event maps.
